{% comment %} image-grid.html — responsive matrix of clickable thumbnails with a lightbox. Clicking a tile opens the full-size image in magnific-popup (already bundled in the Minimal Mistakes theme) with left/right arrows, keyboard navigation and an "Image N of M" counter. Parameters: folder (required) absolute path of the image folder, with trailing slash, e.g. "/assets/images/services/bibs/" alt (optional) prefix used for the alt text / lightbox caption Only direct children of `folder` are used — sub-folders are ignored — and only files with an image extension, so stray files (scripts, notes) can live alongside the images without breaking the grid. Purely numeric filenames (1.png, 2.png, … 22.png) are sorted naturally rather than alphabetically; other names fall back to alphabetical order after them. {% endcomment %} {%- assign folder = include.folder -%} {%- assign alt_prefix = include.alt | default: "Image" -%} {%- assign allowed_ext = ".png,.jpg,.jpeg,.gif,.webp,.svg" | split: "," -%} {%- assign candidates = site.static_files | where_exp: "f", "f.path contains folder" -%} {%- comment -%} Build "::" records joined by ";;" — Jekyll 3.x has no `push` filter, so capture + split is the way to assemble a derived list. {%- endcomment -%} {%- capture records -%} {%- for f in candidates -%} {%- assign expected = folder | append: f.name -%} {%- assign ext = f.extname | downcase -%} {%- if f.path == expected and allowed_ext contains ext -%} {%- assign n = f.basename | plus: 0 -%} {%- assign roundtrip = n | append: "" -%} {%- if roundtrip == f.basename -%} {%- assign sortkey = n | append: "" | prepend: "00000000" | slice: -8, 8 -%} {%- else -%} {%- assign sortkey = f.basename | downcase | prepend: "z_" -%} {%- endif -%} {{ sortkey }}::{{ f.path }};; {%- endif -%} {%- endfor -%} {%- endcapture -%} {%- assign entries = records | split: ";;" | sort -%}
{%- for entry in entries -%} {%- assign parts = entry | strip | split: "::" -%} {%- assign path = parts[1] -%} {%- assign label = path | split: "/" | last | split: "." | first -%} {%- comment -%} The is load-bearing. The theme's main.min.js runs $("a[href$='.png'],...").has("> img").addClass("image-popup") and then binds every .image-popup on the page as ONE gallery. Nesting the one level deeper makes that `> img` selector miss, so these tiles stay out of the theme's global gallery and keep their own per-grid navigation. {%- endcomment -%} {%- endfor -%}
