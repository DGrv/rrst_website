Presenter Auto Tab Switcher

Rotate through your presenter's tabs automatically on a timer.

Works on any RaceResult presenter. Create it once, then reuse it on every presenter. Drag this button up to your bookmarks bar (or copy the code below and save it as a new bookmark).

🔄 Switch Tabs Copied!

Only the interval is baked into the bookmarklet — change the seconds above and it updates automatically. Click the bookmarklet once on any presenter page to start; click it again to stop.

  1. Set the switch interval (seconds) above.
  2. Drag the red 🔄 Switch Tabs button onto your browser's bookmarks bar (one-time setup).
  3. Open any RaceResult presenter with tabs.
  4. Click the bookmark once. Tabs start rotating immediately.
  5. Click the bookmark again anytime to stop.

Why a bookmarklet? The presenter runs on events.raceresult.com, so browser security stops another page from clicking its tabs directly. The bookmarklet runs inside the presenter page, so switching stays smooth with no reload or flicker.
